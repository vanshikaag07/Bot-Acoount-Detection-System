# AI4SMA Landing Page

Next.js + Tailwind CSS landing page for the AI4SMA bot/fake account detector.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Deploy to Vercel

Import the repo in Vercel and set **Root Directory** to `website demo`.
Vercel detects Next.js automatically — no other settings are needed.
